## Selection notes

Use Apple-only mode and a board/model query to narrow these mostly mixed-brand sources.
Only Mac_Shematic_Santale remains in the Apple-exclusive category. These additions do not establish
better M5 coverage; they broaden the candidate pool. External website links are not followed by the
engine. Public channels can contain paid/password-protected posts alongside accessible files.

Skipped candidates included `realschematic_com` (sampled posts were external links), `ariesdownload`
(sampled attachment was a tool comparison, not a schematic), and `schematicsandbios` (handle did not
expose a verifiable channel history). Existing defaults were preserved, not newly endorsed.
