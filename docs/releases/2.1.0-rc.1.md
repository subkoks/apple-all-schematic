# BoardVault 2.1.0-rc.1 — Native macOS

A native SwiftUI interface for downloading, organizing, and browsing your repair references.
This candidate targets Intel Macs running macOS 13 or later. Python and Telethon remain the
Telegram engine; the existing Qt app and CLI are retained.

## Highlights

- A native sidebar with Download, Organize, Library, and Settings, system materials, accent
  color, and System/Dark/Light appearance.
- Prominent search with Any word, All words, or Exact phrase matching; filename/caption scope;
  PDF, boardview, archive, and firmware filters. `M5` does not match `M50`, and board numbers
  remain whole terms. Joined names such as `MacBookPro` are recognized.
- Compact channel progress, speed and current-file ETA, persistent channel ordering, optional
  public subscriber counts, and an Activity log that starts collapsed.
- Guided Telegram login, API credentials in Keychain, Stop with bounded engine teardown, and
  clear errors when the sidecar fails. Login responses and credentials are never logged.
- Scan before organizing, review destinations, then organize or undo the last batch. Existing
  files and newer download records are preserved.
- Searchable product/brand library, Quick Look, Open, Reveal in Finder, Dock progress, keyboard
  shortcuts, and optional completion notifications.
- Ten optional channel additions, offered once and unchecked. See the
  [channel source notes](../channel-sources.md) for coverage and evidence limits.

## Install

Use `BoardVault-2.1.0-rc.1-macos-x86_64.dmg`, or unzip
`BoardVault-2.1.0-rc.1-macos-x86_64.zip`. Drag BoardVault.app into Applications. Retain the Qt
app in a different folder if using both; close other BoardVault clients before shared operations.

The bundle is ad-hoc signed for local integrity. It is not Developer ID signed or notarized.
If macOS blocks it, use the security approval flow described in the
[native user guide](../NATIVE_USER_GUIDE.md). Do not disable Gatekeeper globally.

`SHA256SUMS` verifies the exact release assets. `release.json` records the build version,
architecture, source commit, signature type, and asset hashes.

## Compatibility and limits

- Intel x86_64 only; universal and Apple silicon builds are deferred.
- Target: macOS 13+. Local execution has been demonstrated on Intel Tahoe; an actual Ventura
  runtime check is still pending. Deployment metadata is checked on every bundle.
- API credentials are required from my.telegram.org. No automatic credential/session migration
  runs at launch. An explicit legacy credential import is available in Settings.
- Text search cannot determine a processor from an undocumented board ID. Archive filters use
  the archive's extension; they do not inspect its contents.
- Public follower counts are approximate and may be unavailable. They are not quality ratings.
- Desktop fixture acceptance passed on Intel Tahoe, including compact rows, light/dark views,
  scan, organize, undo, and clean exit. Fresh login, Quick Look, and notifications still need
  manual acceptance. Automated checks use disposable fixtures and mock Telegram clients.
- Native downloads require hard-link support, available on the default APFS filesystem.
